# GIU Software Project I — Travel Planning and Booking Platform

Backend Milestone 1 deadline: November 20, 2026. Frontend Milestone 2 deadline: December 11, 2026.

The repository contains **backend/** (NestJS/TypeScript). Hassib's implemented areas include authentication/profile, administrator account listing/password reset, itineraries and budgeting/FX. Policy acceptance and payment/refund settlement are draft service candidates awaiting the actual booking and delivery integrations. The full milestone remains incomplete.

Start with [backend/README.md](backend/README.md), [implementation status](backend/docs/IMPLEMENTATION_STATUS.md) and [assigned coverage](backend/docs/M1_BACKEND_COVERAGE.md). The official GIU PDF and linked Excel workbook define requirements. Official reference records are reused for itinerary validation; shared reference seeding/APIs remain the assigned owner's work. Material AI assistance is tracked in [AI_PROMPTS.txt](AI_PROMPTS.txt).

Git policy: develop feature work from `develop`; review PRs before merging; do not merge unreviewed code to `main`; keep real `.env` files and secrets out of Git.

# GIU Software Project I — Travel Planning and Booking Platform

Backend Milestone 1 deadline: November 20, 2026. Frontend Milestone 2 deadline: December 11, 2026.

The repository contains **backend/** (NestJS/TypeScript). Authentication and user-profile REST APIs are implemented. The current feature branch also adds notification and administrative audit-log APIs; cross-module event integrations remain in progress. This is an **in-progress build, not a complete or verified milestone**.

Start with [backend/README.md](backend/README.md) and [implementation status](backend/docs/IMPLEMENTATION_STATUS.md). Official GIU PDF is the primary project reference; the separate Excel workbook and four reference CSV datasets must still be supplied for exact requirements and seeding. Material AI assistance is tracked in [AI_PROMPTS.txt](AI_PROMPTS.txt).

Git policy: develop feature work from `develop`; review PRs before merging; do not merge unreviewed code to `main`; keep real `.env` files and secrets out of Git.

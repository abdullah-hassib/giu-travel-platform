# E-ticket fonts

Unmodified Noto Sans and Noto Sans Arabic variable TrueType fonts, downloaded from the Google Fonts primary repository on November 19, 2026. The adjacent OFL files retain each font's copyright and SIL Open Font License 1.1. Assets are copied by Nest into dist/assets/fonts; no system font or runtime network download is required.

- Source: https://github.com/google/fonts/tree/main/ofl/notosans
- NotoSans.ttf SHA-256: bfb7bb691513f12e734dc346c03a03f784912432d7e3fa8e56efcf906fe86b3d
- Source: https://github.com/google/fonts/tree/main/ofl/notosansarabic
- NotoSansArabic.ttf SHA-256: 63111b5b2e074dd48cc67692e0a2726d86ee94c1c37fe8598257b7b4e87e869e

These fonts provide Latin/Greek/Cyrillic and Arabic coverage for the ticket text. They are embedded as subsets in generated PDFs. This is not a claim of full coverage for every writing system.
